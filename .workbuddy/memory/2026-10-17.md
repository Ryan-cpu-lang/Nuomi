- 因此分两条线：(A) Mochi 解释器（宿主机跑源码）；(B) NUC 格式工具链（生成/解析/校验/dump/.nuc 真机 run）。

### 已完成（代码层面，已写盘）
- 多文件结构：`include/mochi.h`、`include/nucfmt.h`、`src/value.c`、`src/reader.c`、`src/env.c`、`src/eval.c`、`src/native.c`、`src/main.c`、`src/nucfmt.c`、`src/nucutil.c`、`Makefile`、`build.bat`、`README.md`、8 个 `samples/*.mochi`。
- Mochi 值体系：NIL/BOOL/NUMBER(double)/OBJ(string|symbol|list|vector|function|env|native)，引用计数 GC + 字符串驻留。
- NUC 实现：构建/解析/校验/dump，严格按规范 48B 头 → 段表(32B) → 符号表(24B) → 重定位表(16B) → 字符串表 → 段数据(4KiB 页对齐)。
- nucutil 命令：`dump` / `validate` / `emit-demo`（生成带 R_X86_64_PC32 重定位的最小示例，call main + mov eax,0x2A + ret，应返回 42）/ `run`（仅 Windows 真机执行）。
